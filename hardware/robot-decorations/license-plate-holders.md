# License Plate Holders

{% hint style="danger" %}
In 2025, for VEX Push Back, license plates are considered functional components. License plate holders and the license plates themselves cannot be 3D printed. Refer to the [manual](https://www.vexrobotics.com/push-back-manual) \<R6> and \<R19> for more information.
{% endhint %}
