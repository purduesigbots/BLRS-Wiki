# Tools

#### Team Checkin

Team Checkin is used when teams arrive at an event to mark them as present. A volunteer should check in a team and give them any information needed for the event as well as checking that all paperwork that is needed has been received.

#### Inspection

Inspection is used when checking a team's robot for legality. This tool records inspection status, but it does not replace the [GRSF](https://library.globalrobotics.org/hc/en-us/articles/52207277648916-Printable-Resources-for-Competitions) or [RECF](https://kb.roboticseducation.org/hc/en-us/articles/4461294967319-Robot-Inspection-Checklist-for-the-RECF-Engage-Robotics-Competition) official robot inspection checklists. Select the checklist for the event’s program and season, and use it alongside the applicable game manual. A team must pass inspection to be added to the schedule. On Pit displays, teams that are checked in show up as grey, teams that are partially inspected are shown as yellow, and teams that have passed inspection are shown as green.

#### Announcements

Announcements are used to show text at the bottom of pit displays. Once published they are shown until the end time that is set when the message is published. Multiple messages can be shown at the same time.

#### Mobile Devices

Mobile Devices is a terminal to setup devices on the same network that are running the [TMMobile](https://www.roboticseducation.org/app/tm-mobile/) app. More information can be found here with a full tutorial on how to pair different devices.
